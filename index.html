Invention 02

The Deadlock-Unraveller-inator

Distributed deadlock detection · C++20

  • C++20 discrete-event simulation (SimCpp20 + coroutines): 5 processes contending for 3 resources, no real threads, fully deterministic.
  • Built a Resource Allocation Graph, derived the Wait-For Graph, and ran two-state DFS cycle detection to extract the exact cycle path.
  • Victim-selection recovery releases a process's resources to break each cycle.
  • Across a 100-unit run: 125 requests, 6 deadlocks detected and recovered.
Source
Invention 03

The Counterfeit-Sniffer-inator

Dual-stream medicine authentication · CV + ML

  • End-to-end vision pipeline that verifies medicine packaging from a standard smartphone camera.
  • Dual OCR architecture with EasyOCR print-quality metrics, fuzzy-matched against a 256,000+ Indian medicines database.
  • Fused OCR metrics with 2,314-dimensional visual features (HOG, LBP, GLCM) into an XGBoost classifier.
  • Results: 96.10% accuracy, 87.84% recall, +6.17 pp precision from OCR fusion.
